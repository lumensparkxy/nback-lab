# F002 — Practice and difficulty selection

Agreement: Draft

## User outcome

Understand the matching task through a guided example and choose a supported level.

## Scope and exclusions

Instructions, short practice and manual n selection. Adaptive progression is excluded.

## Behavior

Reuse the same engine rules as a real session. Practice results must be visibly
distinguished from ordinary sessions. Exact examples and feedback need agreement.

## Acceptance criteria and verification

| ID | Draft criterion | Verification |
| --- | --- | --- |
| AC-01 | A worked example demonstrates the agreed matching rule | Scripted practice flow and content review |
| AC-02 | Only supported n values can begin a session | Boundary tests and emulator selection flow |

## Dependencies

[F001](F001-visual-session.md).

## Open questions

Level range/default, practice sequence, feedback, completion/skipping, and whether
practice is persisted. Obtain agreement before implementation.
